Mob2Con — Design System

Sistema complementar de marca em 4 camadas. Se uma falhar, as outras assumem.

🧱 Estratégia de fallback

1

JSON tokens fonte da verdade

design-tokens.json e layout-templates.json — lidos pelos MCPs (powerbi-layout, powerbi-bridge) e por scripts de automação.

2

CSS variáveis para web e wikis

mob2con.css — espelha exatamente as cores e tamanhos do JSON. Se o tema Power BI não carregar (versão antiga, conflito), qualquer página HTML mantém a marca.

3

HTML preview preview e referência

Este arquivo + templates/*.html renderizam canvas e visuais com as coordenadas exatas — serve de fallback visual quando alguém precisa ver como o dashboard deveria parecer sem abrir o Power BI.

4

Power BI Theme formato proprietário

Mob2Con-Brand-Theme.json em 02-Powerbi-Projetos/ — formato Microsoft. Aplicado via View → Themes → Browse for themes.
