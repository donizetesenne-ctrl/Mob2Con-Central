# 08-Automacao

Ferramentas de automação de workflows e orquestração.

## Sub-repositórios (clones externos)

| Pasta | Descrição | Repo Original |
|-------|-----------|---------------|
| `maestro/` | Orquestrador de workflows | Clone externo |
| `n8n-workflows/` | Workflows n8n para automação | Clone externo |
| `steel-mcp-server/` | Steel MCP Server para browser automation | Clone externo |
| `wexflow/` | Wexflow workflow engine | Pasta local |

> ⚠️ Os sub-repos (`maestro/`, `n8n-workflows/`, `steel-mcp-server/`) estão no `.gitignore` por serem clones de repositórios externos.
> Para instalá-los, clone manualmente cada repo nesta pasta.
