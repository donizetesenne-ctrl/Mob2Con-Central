## 📋 Medidas Novas Criadas

| Medida | Fórmula | Uso |
|--------|---------|-----|
| `% Vendas MoM (Qtd.)` | DIVIDE(M1-M2, M2) | Aba Vendas — variação em unidade |
| `% Vendas M2 vs M3 (Qtd.)` | DIVIDE(M2-M3, M3) | Aba Vendas — evolução 3M |
| `% Ruptura Comercial (Qtd.) Rede` | DIVIDE(Rupt, Venda+Rupt) | Aba Ruptura — % por unidade |
| `% Ruptura Operacional (Qtd.) Rede` | DIVIDE(Rupt, Venda+Rupt) | Aba Ruptura — % por unidade |
| `Estoque (Qtd.) Última Semana` | SUM filtrado última semana | Corrige bug 28bi |
| `DDE Corrigido` | Estoque/VendaDiária | Corrige bug 13k dias |
| `Horas Fornecedor (Projeto)` | Horas por fornecedor | Aba Operacional |
| `% Vendas MoM (Corrigido)` | ROUND + threshold | Elimina floating point |
