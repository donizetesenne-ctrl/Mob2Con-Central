═══════════════════════════════════════════════════════════════

Opção 1 (Mais Fácil):
  → Duplo clique em: executar_sync_diario.bat

Opção 2 (PowerShell):
  Start-ScheduledTask -TaskName "Sync Redshift to Google Sheets"

Opção 3 (Python):
  cd "C:\Users\Donizete Senne\Desktop\Mob2Con-Central"
  python sync_redshift_daily.py


📋 VER LOG DE EXECUÇÃO
═══════════════════════════════════════════════════════════════

  type sync_log.txt

Ou abra o arquivo sync_log.txt no Notepad


⚙️ GERENCIAR AGENDAMENTO
═══════════════════════════════════════════════════════════════

Ver status:
  Get-ScheduledTask -TaskName "Sync Redshift to Google Sheets"

Executar agora:
  Start-ScheduledTask -TaskName "Sync Redshift to Google Sheets"

Desabilitar:
  Disable-ScheduledTask -TaskName "Sync Redshift to Google Sheets"

Habilitar:
  Enable-ScheduledTask -TaskName "Sync Redshift to Google Sheets"

Remover:
  Unregister-ScheduledTask -TaskName "Sync Redshift to Google Sheets" -Confirm:$false

🆘 PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════

Erro de autenticação Google:
  cd "C:\Users\Donizete Senne\.aws\amazonq\universal-control"
  node google-oauth-setup.js

Erro de conexão Redshift:
  - Verifique internet
  - Verifique se cluster está ativo
  - Verifique redshift_config.json

Sincronização não executou:
  - Verifique se PC estava ligado às 06:00
  - Veja histórico no Agendador de Tarefas
  - Execute manualmente para ver erros
