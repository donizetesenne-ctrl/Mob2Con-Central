## 🚀 INSTALAÇÃO RÁPIDA

1. Copie a pasta **`projetos BI`** inteira para o seu **Desktop**
2. Copie as pastas **`projeto`** e **`powerbi-layout-mcp`** para o seu **Desktop**
3. Dê dois cliques em **`INSTALAR.bat`**
4. Siga as instruções na tela

## 🤖 COMO USAR COM AMAZON Q

Após instalar, abra o VS Code e use comandos como:

- `"Conectar no Power BI Nordestão"` — conecta no modelo aberto
- `"Listar todas as tabelas"` — mostra estrutura do modelo
- `"Criar medida DAX de vendas"` — cria medidas automaticamente
- `"Verificar meus emails"` — acessa Gmail
- `"Listar eventos do calendário"` — acessa Google Calendar
