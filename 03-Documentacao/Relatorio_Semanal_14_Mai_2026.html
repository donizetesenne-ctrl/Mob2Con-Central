🎨 Design System em 4 Camadas

Sistema de marca blindado contra falhas

Criado sistema onde se uma camada falhar, as outras assumem automaticamente:

Camada Arquivo Função
1 design-tokens.json + layout-templates.json Fonte única de verdade com cores, fontes, espaços e coordenadas
2 mob2con.css Variáveis CSS espelhando o JSON, classes prontas
3 index.html + 5 previews Visualização do dashboard sem abrir Power BI
4 Mob2Con-Brand-Theme.json Tema Microsoft oficial para Power BI Desktop
Script de Sincronia

sync-tokens.js valida e regenera as camadas automaticamente quando algo muda
