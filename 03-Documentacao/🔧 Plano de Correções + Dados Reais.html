✅ Fix 4 — Nova medida: Alerta GAP Horas (HTML)

NOVO VISUAL

Medida HTML para card de alerta na Visão Executiva com destaque visual do GAP crítico.

// !Alerta GAP Horas (HTML) — nova medida a criar

VAR HorasIdeais   = [Horas Ideais]
VAR HorasReais    = [Horas Realizadas (Projeto)]
VAR GAP           = HorasReais - HorasIdeais
VAR PctExec       = DIVIDE( HorasReais, HorasIdeais, 0 )
VAR Cor           = IF( PctExec >= 0.8, "#107C41", IF( PctExec >= 0.5, "#F46901", "#C00000" ) )
VAR Icone         = IF( PctExec >= 0.8, "✅", IF( PctExec >= 0.5, "⚠️", "🔴" ) )
RETURN
    "<div style='font-family:Raleway,Segoe UI; padding:10px; border-left:4px solid " & Cor & "'>"
    & Icone & " <b>GAP Horas: </b><span style='color:" & Cor & "'>"
    & FORMAT( GAP, "#,##0" ) & "h (" & FORMAT( PctExec, "0.0%" ) & " executado)</span></div>"
